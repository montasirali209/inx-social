# INX Social SEO operations

Canonical origin: `https://social.inaxx.co.uk`

## Implemented in Phase 11.4

- A concise, descriptive title and meta description for the public landing page.
- Canonical and `hreflang` signals, Open Graph and Twitter preview metadata.
- Honest Organization, WebSite, WebPage and web-software structured data.
- A public XML sitemap and robots policy that excludes account, Studio, admin and API areas.
- `X-Robots-Tag: noindex` protection on private product routes.
- A web manifest, bounded static-asset caching and a factual `llms.txt` discovery file.

The schema deliberately contains no invented reviews, ratings, customer counts or performance claims. Software rich-result eligibility may therefore remain limited until genuine review data exists.

## Required owner actions after deployment

1. Open Google Search Console and add the `social.inaxx.co.uk` URL-prefix property.
2. Submit `https://social.inaxx.co.uk/sitemap.xml`.
3. Inspect the canonical home URL and request indexing after the new deployment is live.
4. Run Google Rich Results Test and Schema Markup Validator against the live home page.
5. Test mobile and desktop performance with PageSpeed Insights. Optimise real measured LCP/CLS/INP issues; do not chase a synthetic score without evidence.
6. Add the same sitemap to Bing Webmaster Tools (or import the verified Search Console property).
7. Monitor Search Console indexing, Core Web Vitals, security issues and search queries monthly.
8. Keep titles, descriptions, pricing and structured data aligned with visible page content whenever the product changes.

SEO improves crawlability and presentation but cannot guarantee ranking. Search engines decide indexing and result appearance.
