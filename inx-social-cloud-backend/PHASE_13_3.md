# Phase 13.3 — Exact Publishing Analytics Dashboard

This phase replaces the earlier video-workspace dashboard with the approved premium
publishing analytics layout. It includes the emerald/teal theme and universal Create
New Post navigation from Phase 13.2.2, plus the destination icon correction from
Phase 13.2.1.

The dashboard reads existing overview and publishing-job endpoints. Counts, activity,
recent posts, platform distribution and upcoming schedules are derived from live data.
Engagement surfaces deliberately show an unavailable state until a connected platform
returns permitted analytics; no sample engagement figures are presented as real data.

No database migration, Railway variable or Mac gateway change is required.
