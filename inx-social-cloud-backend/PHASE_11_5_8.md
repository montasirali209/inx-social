# Phase 11.5.8 — Professional Operational Dashboard

This phase replaces the oversized Overview hero with a compact, professional Dashboard inspired by the approved INX Social cover design while keeping every value connected to real workspace data.

## Delivered

- Renamed Overview to Dashboard.
- Renamed Auto Scheduler to Scheduler throughout the customer interface.
- Moved Connected Pages below Settings in the primary navigation.
- Added four concise operational cards: content import, schedule slots, upload progress and the active connected Page.
- Added a real content queue populated from retained scheduler jobs.
- Added a compact publishing calendar populated from local jobs and Facebook scheduled posts.
- Preserved drag-and-drop imports, folder imports, slot checking, progress metrics and connection tools.
- Moved secondary controls into small disclosures to reduce visual noise.
- Added responsive two-column and single-column layouts plus Clean Light theme support.

No database migration, Railway variable, Mac gateway change or Ollama restart is required.
